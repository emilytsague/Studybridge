Was ist ein Geschäftsprozess?

Ein Geschäftsprozess verbindet mehrere Tätigkeiten mit einem Ziel. Beispiel: Eine Bibliothek erhält eine Reservierung, prüft die Verfügbarkeit und stellt das Buch bereit.
